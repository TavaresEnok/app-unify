# Guia de Estilo Visual - Layout 08 (Eco-Minimal)

## Tema Geral
- Estética: Minimalista com toques ecológicos, curvas suaves, foco em usabilidade e acessibilidade.
- Inspirações: Tendências 2025 de UI/UX minimalista, designs eco-friendly, micro-interações suaves.

## Paleta de Cores
- Primary: #4CAF50 (Verde Floresta)
- Secondary: #2196F3 (Azul Céu)
- Background: #F0F4F8 (Claro) / #1E1E1E (Dark mode opcional)
- Text Primary: #333333
- Text Secondary: #757575
- Accent: Tons terrosos para destaques.

## Tipografia
- Fonte Principal: 'Inter' (sans-serif para legibilidade)
- Títulos: 'Poppins' (bold, tamanhos 20-42pt)
- Corpo: Tamanhos 12-16pt, line-height 1.5

## Elementos Visuais Únicos
- Cards: Bordas arredondadas (16px), shadows suaves.
- Animações: Fades e scales orgânicos.
- Ícones: Simples, com hover effects (scale 1.1).
- Layout: Amplo white space, grid responsivo.

## Acessibilidade
- Contraste: WCAG AA compliant (mínimo 4.5:1).
- Responsividade: Media queries para mobile/desktop.
- Haptic Feedback: Mantido para interações.
