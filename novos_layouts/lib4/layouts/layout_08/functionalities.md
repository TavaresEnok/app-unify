# Funcionalidades Mantidas - Layout 08

Baseado no Layout 06, todas as funcionalidades foram preservadas:

## Dashboard
- Header com menu, nome do usuário, notificações.
- Cartão de fatura com valor, status, dias restantes.
- Ações rápidas: Faturas, Velocidade, Suporte, Wi-Fi.
- Cartão de plano com download/upload.
- Lista de serviços: Diagnóstico, Traceroute, Consumo, Meu IP, Contrato.
- Bottom navigation: Home, WiFi, Invoices, Support, Profile.
- Refresh indicator com haptic feedback.

## Login
- Campo de CPF/CNPJ.
- Botão de login com loading e error handling.
- Logo dinâmico de config.
- Animações de background.
- Navegação para dashboard após sucesso.

## Outras
- Integração com providers (auth, config).
- Chamadas de serviço (onNavigate, onRefresh).
- Compatibilidade com temas white-label.
